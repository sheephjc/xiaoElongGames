# 首页场景与游戏选择

首页采用小鳄龙草地场景与右侧三个纵向栏目入口。进入游戏大厅时只切换右侧面板，
保持场景与顶部昵称／偏好工具。项目当前为可返回的占位面板，成员介绍直接打开中央展开页面。
首页三个栏目入口对齐并统一使用浅色牌面，只保留图标、标题与箭头；
移除品牌副标题、首页说明、栏目副标题与编号、左侧欢迎文案及右下角标语。

## 组件与状态

- `App` 管理游戏状态及首页面板 `main | hall | projects | members`，从游戏详情返回 `hall`。
- `HomeScreen` 管理栏目切换、确认反馈、焦点和重复点击锁；场景、栏目入口和游戏卡拆成独立组件。
- 游戏选择按注册表顺序展示已上线的出包魔法师、鳄龙咆哮、暗棋，人数和玩法读取注册表。
- 大厅面板在桌面上靠上放置，游戏卡列表独立上下滚动；标题和返回按钮保留在列表外。
- 昵称最多 8 字，空值为「你」，持久化到 `tm-player-name`；存储不可用时继续在内存中游玩。
- 首页音效／动效复用 `tm-settings`，鳄龙咆哮仍保留独立游戏偏好和按需加载。
- 宽度 ≥1024px 使用左右构图；较小屏幕上下排列并自然滚动。所有新主题样式限定在 `.home`。
- 图像使用 Vite `BASE_URL` 相对寻址；场景失败时显示渐变背景，封面失败时保留文字游戏入口。
- 悬停约 160ms、按下约 80ms、光圈 300ms、面板进入 220ms。关闭动效或系统减少动态效果时取消动画。
- 使用原生按钮，栏目切换后聚焦面板标题；340ms 内的重复激活不产生第二次导航。

素材来源：[协作者素材目录](https://github.com/sckall/xiaoElongGames/tree/main/apps/web/public)。
场景与两张封面原样复用，未移植协作者的云入口、演示数据或联机协议扩展。

## 游戏与项目的全部展示模式
